## 1. Defect Classification Policy

- **P0 — Critical Security or Data Integrity Failure**: Cross-tenant leakage, RLS bypass, unanchored hallucinated findings persisted, or mutation of approved immutable report versions.
- **P1 — Major Workflow or Functionality Failure**: End-to-end pipeline breakage, cross-wave state inconsistency (e.g., human-rejected rules/findings still presented as active in reports/dashboard/Q&A), or non-idempotent test fixture collision.
- **P2 — Partial Functionality or Significant Usability Issue**: Missing supporting evidence array on serialized modernization recommendations.
- **P3 — Minor UI or Non-Critical Issue**: Pytest collection warnings on production classes starting with `Test*`, or stale milestone badges on the landing/settings pages.
